A program that writes the one line a gamer texts the boss to skip work on GTA 6 launch week — at most 20 words, plain text, believable enough that a tired manager would almost buy it. The excuse leans on a boring, specific, double mundane failure: a broken lift plus stairs shut for repainting, leaving the sender genuinely trapped on the ninth floor till lunch.

## Run it

```sh
node main.ts
```

It writes the excuse to `/output/entry.txt` (one line, 20 words, 115 characters — inside the 1–140 character gate).
